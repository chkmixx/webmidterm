 Project Description

Our project is a personal blog about Emma Watson. She was born in France in 1990 and is an English actress, model, and activist.

The website includes information about her lifestyle, food, travel, technology, books, and personal life.

The website consists of 6 connected pages. We used HTML, CSS, JavaScript, jQuery, and Bootstrap to create the website.

Our website is responsive and works on different screen sizes.

# Theme Toggle

We added a theme toggle to the website.

The selected theme is saved in `localStorage`, so it remains active after refreshing the page.

# Sign-In Form

We added a sign-in form to the website.

JavaScript validates the form and saves the login state in `localStorage`.

The login state remains after refreshing the page.

Users can also sign out, which clears the saved login state.

# API Integration

We integrated a public API into our project.

We use JavaScript `fetch()` to send a request to the API.

The data is received in JSON format and displayed dynamically on the page.

Users can search for books using the API.

For example, we can search for **Little Women** and display the book results.

# FAQ

We added an FAQ section to the Lifestyle page.

Users can click a question to open or close the answer.

We use jQuery `slideToggle()` to create a smooth animation.

The FAQ also includes **+** and **−** indicators to show whether an answer is open or closed.

- 6 connected pages
- Navigation bar
- Responsive design
- Home page
- About page
- Tech page
- Travel page
- Lifestyle page
- Food page
- Contact form
- Information table
- Bootstrap grid
- Flexbox and CSS Grid
- Hover and focus effects
- Mobile and tablet layouts
- Footer with contact and social links

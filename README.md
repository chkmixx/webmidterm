# Emma Watson Personal Blog

## Project Topic

Personal blog about Emma Watson.

## Group Members

- Nurbolsyn

## Project Description

This is a multi-page personal blog about Emma Watson. The website includes information about her lifestyle, food, travel, technology and personal life. The website is responsive and works on different screen sizes.

The project also includes interactive JavaScript and jQuery functionality for user interaction and dynamic content.

## JavaScript Features

### Registration Validation

The registration form uses client-side JavaScript validation.

It checks:

- Required fields
- Valid email format using RegEx
- Password length
- Password strength
- Password confirmation
- Error messages
- Successful form submission

### Search and Filtering

The Tech page includes:

- Dynamic search
- Case-insensitive search
- Category filtering
- Input events
- No page reload

Users can filter posts by:

- All
- Technology
- Education
- Digital

### CRUD Operations

The About page includes a dynamic books table.

Users can:

- **Create** a new book
- **Read** books from the table
- **Update** book information
- **Delete** books
- Confirm before deleting

### Image Gallery

The Travel page includes a Bootstrap image gallery.

The gallery provides:

- Clickable images
- Lightbox effect
- Previous image button
- Next image button
- Close button
- jQuery `fadeIn()`
- jQuery `fadeOut()`
- jQuery `animate()`
